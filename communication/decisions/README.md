# Decisions

บันทึกการตัดสินใจที่ **มนุษย์อนุมัติแล้ว** (หรือรออนุมัติ) 1 การตัดสินใจ = 1 ไฟล์ `DEC-nnn_<slug>.md` เพิ่มได้อย่างเดียว ถ้าจะเปลี่ยนการตัดสินใจเดิม ให้เพิ่มไฟล์ใหม่ที่ `supersedes` ไฟล์เดิม

ช่องที่ต้องมี: `id`, `date`, `status` (`Proposed` | `Approved` | `Superseded`), `approvals` (ใคร อนุมัติเมื่อไร หรือ `pending`), `supersedes`, ตามด้วยหัวข้อ **Decision**, **Why**, **Affects**

AI เขียนไฟล์ `Proposed` ได้ แต่เปลี่ยนเป็น `Approved` ได้เมื่อมีหลักฐานการอนุมัติของมนุษย์ที่ระบุชื่อ (เช่น ข้อความ/คำสั่งในเซสชัน) เท่านั้น
